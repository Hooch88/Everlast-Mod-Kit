# Everlast Project Rules

- Always consult [`EVERLAST_INTERNALS_MAP.md`](../EVERLAST_INTERNALS_MAP.md) before searching or scanning game files, databases (`ItemDefs.db`, `ComponentSetDefs.db`, `EstatePlotDefs.db`, `Raptor.Game.db`), metadata (`global-metadata.dat`), or DLL binaries (`GameAssembly.dll`).
- Do not run blind file scans or decompilation across the game directory when values or offsets are already cataloged in the knowledge map.
